# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:

- Be respectful and welcoming.
- Assume good intent.
- Give constructive feedback.
- Focus on what is best for the community.

Harassment and personal attacks are not tolerated.

To report unacceptable behavior, contact the maintainer privately through GitHub. Use [private vulnerability reporting](https://github.com/its-harsh-here/ASCEND/security/advisories/new) if the matter is sensitive. All reports are handled confidentially.
